# Analysis of Toronto Auto Theft Dataset
This project uses the Auto Theft dataset from the Toronto Police Service Open Data.             
The dataset represents the auto theft occurrences reported since 2014 up to 2025, including when and where each theft was reported.         
Each row contains details such as the report and occurrence date, the neighbourhood, the type of location where the theft took place, and the estimated coordinates of the incident.        
In this project I aim to understand the trends and patterns within the data and explore the dataset to answer analytical questions about auto theft in Toronto.  

[Toronto Auto Theft Dataset](https://data.tps.ca/datasets/TorontoPS::auto-theft-open-data/about)
